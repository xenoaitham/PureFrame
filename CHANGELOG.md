# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-beta] - 2026-05-07

### Added
- Core AI detection pipeline integrating NudeNet, CLIP, and PANNs audio analysis.
- Scene fusion and dynamic temporal smoothing algorithms.
- `pureframe` CLI for planning, rendering, and batch processing.
- Multi-profile hardware acceleration (CPU, LOW, MEDIUM, HIGH, MAC).
- Checkpoint-based crash recovery for folder processing.
- JSON-based `censorplan` files for manual review and whitelisting.
- Initial experimental Tauri desktop GUI.
