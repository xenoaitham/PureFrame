## Known Issues for v0.1.1 (File as GitHub Issues After Launch)

1. **Resumability + output path**: Jobs keyed on input path + config hash; re-running with a different `--output` path skips re-processing because the job is already DONE. Fix: key output path separately or add `--force` flag.
2. **`pureframe jobs cleanup --all`**: The `--all` flag isn't implemented; `cleanup` only supports individual job IDs currently.
3. **CPU benchmark anomaly**: CPU profile appears faster than GPU profiles on zero-detection synthetic clips because CUDA init overhead is not amortised across zero-frame detections. README/BENCHMARKS already notes this but a better profiling mode would help.
